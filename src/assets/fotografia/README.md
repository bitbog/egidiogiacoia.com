# Galleria Fotografica: Istruzioni

Le immagini inserite in questa cartella (alla radice del progetto) verranno copiate ed esposte automaticamente nella pagina **Fotografia** del sito, senza bisogno di scrivere configurazioni o codice aggiuntivo.

## Come aggiungere foto

1. Salva i file delle immagini direttamente in questa cartella (`fotografia/`).
2. Sono supportati i formati standard più comuni (`.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`).
3. Il build si occuperà in automatico di esporle.

*Nota: I nomi dei file (sostituendo trattini o underscore con spazi ed eliminando l'estensione) saranno usati come didascalia visibile al passaggio del mouse (hover).*
